Sam is the creative director and primary author of the Lanes and Lies GDD suite. He has strong design-doc discipline (knows the 8-section standard, phase-gating, server-authoritative model). He works at the level of a senior game designer: he provides locked upstream decisions and locked interaction patterns, and wants the UX agent to validate flows, flag gaps, and produce behavioral rules — not author GDD text directly. He will author the GDD himself from the UX agent's spec output.

Collaboration style: question-first, spec-consultant mode. Do not write GDD prose unprompted. Flag ambiguities as explicit numbered rules or named gaps. Reference UX theory only when it directly informs a decision the user must make.
