## Comment communiquer avec Codex

Codex est l'orchestrateur d'implémentation dans un projet séparé. Il lit les story files de CE projet. Quand tu veux qu'il fasse quelque chose :

```
[Story ID] is READY at [path].
Claim and implement. Governing ADR: [ADR-XXX].
[Specific notes from story file].
```

Pour les blockers :
```
[Story ID] is BLOCKED by [reason].
Do not claim until [condition] is resolved.
```

Pour les story-done : toujours vérifier CI vert sur le commit hash avant de lancer `/story-done [path]` dans CE projet.
